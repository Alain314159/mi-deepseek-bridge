# Instrucciones para DeepSeek

## Opcion A - Instrucciones personalizadas (una sola vez)

En DeepSeek: Ajustes - Instrucciones personalizadas. Pegar el texto del SYSTEM_PROMPT que esta en extension/content.js.

## Opcion B - Instruccion por chat

En cada chat nuevo, toca el boton I en el panel de la extension. Pega las instrucciones en el input.

## Opcion C - Deteccion automatica

No requiere nada. La extension detecta bloques que parezcan comandos shell y les pone un boton.

## Auto-pilot

Activa el toggle Auto en el panel. Los comandos se ejecutan solos y el resultado se pega en el chat automaticamente.
